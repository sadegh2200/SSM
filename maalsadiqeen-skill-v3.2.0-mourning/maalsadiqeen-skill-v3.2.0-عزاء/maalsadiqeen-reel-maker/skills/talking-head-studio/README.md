# Talking-Head Studio

**یک ویدیو از خودت می‌دهی، یک ویدیوی تمام‌شده و بازبینی‌شده تحویل می‌گیری.**

```
python3 scripts/studio.py TALK.mp4 --out final.mp4 --captions talk.srt --preset social
```

| مرحله | چه می‌کند |
|---|---|
| اندازه‌گیری | نقشهٔ سکوت، بلندی، نویز، چهره در هر نمونه، روشنایی، لرزش |
| تصمیم | برداشت‌ها، قاب‌بندی/زوم، نور و رنگ، زنجیرهٔ صدا، زیرنویس → `plan.json` |
| رندر | یک گراف ffmpeg: برش → اتصال → قاب → ظاهر → زیرنویس → AAC |
| بازبینی | ۱۰–۱۲ بررسی عددی + شیت بازبینی → `verify.json` |
| تحویل | `report.md`، `manifest.json`، `srt` باززمان‌بندی‌شده |

## چه چیزهایی را «تنظیم» می‌کند

- حذف سکوت و مکث‌های بلند (بدون قطع هیچ کلمه‌ای)
- قاب‌بندی ۹:۱۶ / ۱:۱ / ۱۶:۹ با دنبال‌کردن سوژه؛ یا حالت باند با پس‌زمینهٔ بلور
- زوم و پانچ‌این هر برداشت (`punch`, `pulse`, `in`, `out`)
- نوردهی بر اساس روشنایی خود سوژه + اصلاح نوسان نور در زمان
- تعادل رنگ (grey-world، محدود) + چهار گرید آماده
- حذف نویز هوشمند (فقط اگر نویز باشد)، EQ، بلندی هدف پلتفرم
- زیرنویس فارسی/عربی/انگلیسی با بازنگاشت زمان پس از برش + کارائوکه

## پیش‌نیاز

```bash
bash scripts/bootstrap.sh --check   # چه چیزی کم است
bash scripts/bootstrap.sh           # نصب
```

ffmpeg (با libass)، ffprobe، python3، numpy، opencv<5، pillow. بدون کلید API و بدون دانلود مدل.

## محدودیت‌ها (صریح)

- **رونویسی نمی‌کند.** مدل ASR دانلود نمی‌شود؛ برای زیرنویس، SRT لازم است.
- **حذف «اِ… اِ…» وسط جمله نمی‌کند** — این کار زمان‌بندی کلمه می‌خواهد که همان ASR است.
  (برای آن: اسکیل‌های همراه `cut-video`، `clipify`، `talking-head-editor`، `video-use`.)
- **ویدیو تولید نمی‌کند**؛ فقط چیزی که هست را تدوین می‌کند.
- هیچ عددی را حدس نمی‌زند: اگر اندازه‌گیری ممکن نباشد، فیلد `null` و هشدار صریح می‌شود.
