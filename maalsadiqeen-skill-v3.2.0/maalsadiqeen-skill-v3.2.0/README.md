# maalsadiqeen

مخزن اسکیل **«ریل‌ساز مع الصادقین»** (`maalsadiqeen-reel`) — از **هر متنی** (یک صفحهٔ کتاب، متن سخنرانی،
پیام فورواردی، سؤال مخاطب) یا از **ورق‌های برند صفحه**، به یک ریل عمودی ۱۰۸۰×۱۹۲۰ و ۳۰–۶۰ ثانیه‌ای:
بریف → **چهار سناریو و انتخاب شما** → ساخت → کیت انتشار سه‌پلتفرمی.

راهنمای کامل خودِ اسکیل: [`SKILL.md`](maalsadiqeen-reel-maker/maalsadiqeen-reel/SKILL.md)
· معرفی و نصب: [`maalsadiqeen-reel-maker/README.md`](maalsadiqeen-reel-maker/README.md)
· نقشه و گزارش ارتقا: [`UPGRADE-PLAN-fa.md`](maalsadiqeen-reel-maker/UPGRADE-PLAN-fa.md)

## نسخهٔ ۳.۲ — چه چیزی تغییر کرد

| محور | نسخهٔ ۲ | نسخهٔ ۳ |

## هویت برند (فاز ۱ ارتقا)

- **وعده:** یک نصّ، منبعش، و آنچه این هفته از تو می‌خواهد — در چهل ثانیهٔ آرام.
- **سه لایه:** نصّ (عیناً + ارجاع) · شرح (عالم نام‌دار) · استنباط (از ما، علامت‌دار). بیننده باید از
  خودِ صفحه بفهمد هر جمله در کدام لایه است.
- **الزامی:** بلوک «الأثر في الحياة» — یک کار مشخص در هفتهٔ مخاطب، نه شعار.
- **ممنوع:** فروش ترس، کلیک‌بیت، لهجه، ایموجی، «!»، توهین به گروه‌ها، منبع یا درجهٔ ساختگی، «تابعونا/لایک».
- **اجرای ماشینی:** `copy_lint.py` (لایه‌ها، اعراب، منع‌ها، بودجهٔ خواندن)، `captions.py` (سقف هر پلتفرم)،
  `comments.py` (۷ اسلات، ≤۳۰۰ نویسه)، `scenarios.py validate` (گیت چهار سناریو + بودجهٔ متن بلند).
