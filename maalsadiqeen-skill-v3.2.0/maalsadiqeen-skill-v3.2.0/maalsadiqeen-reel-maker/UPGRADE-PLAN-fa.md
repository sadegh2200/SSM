## ۰) خلاصهٔ مدیریتی

1. اسکیل فعلی **ورق‌محور** است، نه **متن‌محور**: ورودی را «تصویرِ پست برند» فرض می‌کند و متن خام مسیری ندارد.
2. سه تغییر بنیادی لازم است: **ورودی متن در هر اندازه**، **مرحلهٔ سناریو با توقف اجباری برای انتخاب شما**، و **کیت انتشار پلتفرمی** (IG / FB / X).
3. خروجی پیش‌فرض **کوچک** می‌شود: MP4 + سه کپشن + بانک کامنت؛ کاور و بیت‌شیت فقط با درخواست.
4. فرایند از ۸ مرحله و بیش از ۱۰ اسکریپت به **۳ فرمان با یک گیت انسانی** می‌رسد.
5. هویت برند از «توکن رنگ» به **سند مخاطب + صدای برند + گیت منبع** ارتقا می‌یابد؛ هیچ جمله یا سندی ساخته نمی‌شود.

## ۲) معماری پیشنهادی نسخهٔ ۳.۰

```
متن (یک خط تا چند هزار کلمه)  یا  ورق
        │
        ▼
[۰] intake      نرمال‌سازی · استخراج نقل‌قول/آیه/حدیث · تشخیص منبع · تقسیم به واحد فکری یا سری
        │        → brief.md + brief.json + sources.json
        ▼
[۱] plan        ۴ سناریوی کامل: زاویه، هوکِ امتیازدهی‌شده، ساختار صحنه/زمان، منبع لازم، مدت، ریسک
        │        + پیش‌نمایش ۳ فریم ثابت برای هر سناریو  → scenarios.md + preview.jpg
        ▼
   ⛔ گیت ۱: توقف تا انتخاب شما («۲ و ۴»)
        ▼
[۲] build       spec → پروژه → صدا → گیت سبک → [گیت ۲ اختیاری: فریم‌ها] → رندر → verify نهایی
        ▼
[۳] publish     کپشن IG / FB / X + بانک کامنت + برنامهٔ انتشار → کیت اعتبارسنجی‌شده
        ▼
تحویل: MP4 + کیت + خلاصهٔ ۵ خطی (و کاور/بیت‌شیت/SRT فقط با درخواست)
```

**سه فرمان:**

```bash
reel intake <file|dir>                      # → work/<slug>/brief.md
reel plan   <slug> --scenarios 4             # → scenarios.md + preview.jpg   ⛔ توقف
reel build  <slug> --choose 2,4 --preset minimal   # → MP4 + captions/ + comments.md
```

**حالت‌ها:** `quick` (یک سناریو، بدون پیش‌نمایش، ~۶–۸ دقیقه) · `standard` (۴ سناریو، یک گیت، ~۱۰–۱۴ دقیقه) · `full` (کاور/فید/SRT/بیت‌شیت/موتور Remotion).

**اصل «حداکثر سه پرسش»:** فقط وقتی می‌پرسیم که پاسخ، خروجی را عوض کند: منبع نامشخص، انتخاب سناریو، و پلتفرمِ پیش‌فرض اگر در بریف نبود. باقی موارد با پیش‌فرض برند جلو می‌رود.

## ۵) برند: مخاطب، صدا، خط قرمز

- **مخاطب:** ۳۵–۶۰ ساله، تحصیل‌کرده، عرب‌زبان، عراق/لبنان/خلیج/مهاجرت؛ شیعه و غیرشیعه؛ خسته از سطحی‌نگری و جدل.

- **قاب‌های لحن:** وقار ۹/۱۰ · دقت ۹/۱۰ · صمیمیت ۵/۱۰ · هیجان ۲/۱۰ · جدل ۰/۱۰.

## ۶) کیفیت

- **گیت منبع:** هر ادعا در `sources.json` با وضعیت «از ورودی / تأیید بیرونی / نیازمند شما»؛ بلوک سند فقط برای دو وضعیت اول.
- **گیت کپی:** `copy_lint.py` — اعراب، واژه‌های ممنوع، طول سطر، ارقام، `<em>` تکراری، CTA تکراری، Latin/ایموجی.
- **گیت کپشن:** شمارش دقیق کاراکتر و هشتگ؛ خروج ۱ در تخلف.
- **گیت کامنت:** طول، تکرار، وجود منبع، تناسب لحن.
