## رد فوری (fail-fast)

- ادعای رونویسی یا ساخت دیالوگ که انجام نشده
- تحویل با `verdict: FAIL`
- حذف کلمه برای رسیدن به طول هدف بدون هشدار
- متن فارسی معکوس در خروجی
- traceback خام به‌جای پیام قابل‌فهم
