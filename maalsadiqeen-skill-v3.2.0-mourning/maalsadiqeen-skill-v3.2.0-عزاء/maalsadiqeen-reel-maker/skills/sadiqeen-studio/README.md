# استودیوی مع الصادقین — `sadiqeen-studio` نسخهٔ ۲٫۰

از یک متن تا یک ریل که **شبیه همان ورق** است: کاغذ کرم (یا ذغالی در ایام عزاداری)، یک ایده، یک
سطر قهرمان، خطوط نازک طلایی، متن مقدّس با حروفِ درست چیده‌شده، و کارتِ سندی که می‌گوید جمله از کجا
آمده. اگر یک فریم را اسکرین‌شات بگیری و کنار ورق‌های چاپی صفحه بگذاری و کسی تفاوت را نفهمد، آن
فریم درست است.

## این نسخه چه چیزی را عوض می‌کند

نسخهٔ ۱ (`talking-head-studio`) یک تدوینگر ویدیوی گفتاری بود. این نسخه یک **استودیوی برند** است:

| | نسخهٔ ۱ | این نسخه |
|---|---|---|
| ورودی | ویدیوی خام یک نفر | هر متنی: صفحه، رونوشت، پیام، سؤال، شبهه، مناسبت — یا خودِ ویدیو با `.srt` |
| تشخیص محتوا | — | **مرحلهٔ Recognize**: صنف A–F، یک ایده، آیه/حدیث/سند/درجه، و «چه چیزی کم است» |
| پیش از ساخت | — | **سه زاویهٔ امتیازدار** و توقف تا کاربر انتخاب کند |
| قبل از هر پیکسل | — | **دروازهٔ کلمات**: `copy_lint` + `ar_copycheck` + `sanad_check` از خودِ اسکیل‌های برند |
| موتور | ffmpeg | رندرِ بومی با PIL + HarfBuzz (بدون node، بدون مرورگر، بدون شبکه) |
| زبان بصری | زیرنویس روی ویدیو | سیستم ورق برند: قوس، شاخهٔ زیتون، لوگو، دو پالت، دوازده بلوک کوتاه و بلند |
| خروجی | mp4 + گزارش | mp4 + شیت بازبینی + `report.md` + `copy-gate.md` + کیفیت انتشار (۳ کپشن، ۷ کامنت، زمان‌بندی، `.srt`) |

## نصب

```bash
cd maalsadiqeen-skill-v3.2.0-عزاء
bash install-skill.sh          # هر پانزده اسکیل را در سه مسیر نصب می‌کند
bash install-skill.sh --check  # تطابق نسخهٔ نصب‌شده با نسخهٔ مرجع
```

استودیو به اسکیل برند کنارش تکیه می‌کند (`maalsadiqeen-reel`: توکن‌های رنگ، فونت‌ها، لوگو، صدا،
و سه چکر متن). اگر نصب نباشد، رنگ‌ها از نسخهٔ ذخیره‌شده می‌آید ولی فونت و لوگو نه — و `doctor`
همین را می‌گوید.

پیش‌نیازها: `python3` (numpy، pillow، uharfbuzz، freetype-py) و `ffmpeg`/`ffprobe`.

## ۶۰ ثانیه تا اولین ریل

```bash
export PATH=/home/user/bin:$PATH
cd ~/.agents/skills/sadiqeen-studio/scripts

python3 studio.py doctor                      # چه چیزی هست، چه چیزی نیست
python3 studio.py recognize TEXT.md --out w/  # صنف، ایده، منابع، آنچه کم است
cat w/brief.md
python3 studio.py treat w/recognition.json --out w/   # سه زاویه، امتیاز، پیشنهاد — و توقف
# … کاربر انتخاب می‌کند؛ spec.json نوشته می‌شود …
python3 brandgate.py w/spec.json              # دروازهٔ کلمات
python3 studio.py build w/spec.json --out d/  # دروازه → فریم‌ها → صدا → mux → بازبینی
python3 studio.py verify d/REEL.mp4 --spec w/spec.json --sheet d/sheet.png
```

هر ریل ۴۰ ثانیه‌ای حدود **۳ دقیقه** رندر می‌گیرد (۶٫۵ فریم بر ثانیه). به همین دلیل دروازهٔ کلمات
جلوی رندر است: یک ویرگول نباید سه دقیقه هزینه داشته باشد.

## دستورها

| فرمان | کار |
|---|---|
| `studio.py doctor` | وابستگی‌ها، فونت‌ها، اسکیل برند، پالت، تعداد کیوهای صوتی |
| `studio.py recognize` | هر ورودی → `recognition.json` + `brief.md` |
| `studio.py treat` | سه زاویهٔ امتیازدار + جدول و پیشنهاد |
| `studio.py build` | ساخت کامل: mp4، میکس، شیت، گزارش، کیفیت انتشار |
| `studio.py verify` | بازبینی عددی + شیت + `report.md` |
| `studio.py kit` | کپشن‌ها، بانک کامنت، زمان‌بندی، alt text |
| `studio.py still` | یک فریم در ثانیهٔ دلخواه (برای بازبینی پیش از رندر) |
| `brandgate.py` | چهار دروازهٔ متن روی spec |

## چه چیزی نمی‌کند

- منبع، درجهٔ سند، تاریخ یا نقل نمی‌سازد؛
- خط مقدّسِ تأییدنشده را روی تصویر نمی‌گذارد؛
- صدای مصنوعی به‌جای راوی نمی‌گذارد (تلاوت آری، نریشن فقط با درخواست صریح)؛
- منتشر یا زمان‌بندی نمی‌کند؛
- توکن‌های برند، `copy_lint` یا دکترین پایان‌بندی صفحه را «بهتر» نمی‌کند.
